Inline link:
[Visit MDN](https://developer.mozilla.org)

Link with a title (shows as a tooltip):
[Visit MDN](https://developer.mozilla.org "MDN Web Docs")

Reference-style link (handy for reusing the same URL twice):
[Visit MDN][mdn]

[mdn]: https://developer.mozilla.org

Automatic link - just wrap a bare URL in angle brackets:
<https://developer.mozilla.org>

Image - same syntax as a link, with a leading !:
![Alt text describing the image](https://example.com/screenshot.png)

Image with a title:
![Alt text](https://example.com/screenshot.png "Shown on hover")
