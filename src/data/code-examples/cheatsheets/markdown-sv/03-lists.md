Osorterad lista (-, * och + fungerar alla):

- Första punkten
- Andra punkten
  - Nästlad punkt (indrag med 2 mellanslag)
  - Ytterligare en nästlad punkt
- Tredje punkten

Numrerad lista:

1. Första steget
2. Andra steget
   1. Nästlat steg
   2. Ytterligare ett nästlat steg
3. Tredje steget

Kombinera en lista med ett stycke genom att indentera stycket 4 mellanslag:

- Punkt med extra detalj
    Den extra detaljen fortsätter samma listpunkt.
